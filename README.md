# 📝 Todo Overlay

Todo list + ปฏิทิน แบบ overlay ติดหน้า desktop สำหรับ Windows 10/11
เขียนด้วย Python + Tkinter ล้วนๆ **ไฟล์เดียวจบ ไม่ต้องลง library เพิ่ม**

ได้แรงบันดาลใจจาก Rainmeter / Rainlendar แต่ปรับแต่งง่ายกว่าเพราะแก้โค้ดเองได้เลย

## ✨ ฟีเจอร์

- **Todo list** — หัวข้อ + หมายเหตุ, สถานะ 3 แบบ (รอ ○ / กำลังทำ ◐ / ทำแล้ว ✔)
- **Priority พร้อมสีอัตโนมัติ** — สูง 🔴 / กลาง 🟡 / ต่ำ ⚪
- งานที่เสร็จแล้ว **ขีดฆ่า + จางลง + เลื่อนไปอยู่ท้ายรายการ** และซ่อน/โชว์ได้ในตั้งค่า
- เก็บ **วันที่สร้าง + วันเป้าหมาย** วันเลยกำหนดขึ้นสีแดง
- **ลากเรียงลำดับงาน** ได้ตามใจ
- **ปฏิทินรายเดือน** เริ่มวันอาทิตย์, เสาร์-อาทิตย์สีแดงอ่อน, วันนี้พื้นสีฟ้า
- **Sync Google Calendar (อ่านอย่างเดียว)** ได้ 3 วิธี — วันที่มี event เป็นสีเหลือง คลิกดูรายชื่อ event ได้
- **Overlay ไร้ขอบ** กลืนกับ wallpaper, ลากย้ายได้, จำตำแหน่ง
- **โหมดล่องหน** — ตัวหนังสือลอยบน wallpaper ไม่มีแผงพื้นหลัง
- ปรับ **ฟอนต์ / ขนาด / ความทึบ (opacity)** ได้
- **ธีมสีเข้ม / สว่าง (พาสเทล)** เลือกได้ในตั้งค่า
- **Auto-backup** ข้อมูลงานทุกครั้งที่เปิดโปรแกรม (เก็บ 2 ชุดหมุนเวียน)
- **Worklog อัตโนมัติ** — งานที่ติ๊กเสร็จถูกบันทึกลง `worklog.json` ถาวร
  ไว้ใช้รวบรวมผลงานตอนประเมินประจำปี (ลบงานทิ้งภายหลังก็ไม่กระทบประวัติ)
- **เปิดพร้อม Windows** อัตโนมัติ (ตั้งได้ในแอพ)
- ข้อมูลเก็บเป็น **JSON ไฟล์เดียว** เปิดอ่าน/แบ็คอัพง่าย

## 🚀 ติดตั้งและใช้งาน

1. ติดตั้ง [Python 3.8+](https://www.python.org/downloads/) (ติ๊ก **Add Python to PATH** ตอนติดตั้ง)
2. ดาวน์โหลด `todo_overlay.pyw` ไปไว้ในโฟลเดอร์ที่ต้องการ
3. ดับเบิลคลิกเปิดได้เลย (`.pyw` รันโดยไม่มีหน้าต่าง console)

| ปุ่ม | หน้าที่ |
|---|---|
| ＋ | เพิ่มงาน |
| 📅 | เปิด/ปิดปฏิทิน |
| 🔄 | ดึงข้อมูลปฏิทินทันที (ฟ้อง error ถ้าเชื่อมต่อไม่ได้) |
| ⚙ | ตั้งค่า |
| ✕ | ปิดโปรแกรม |

- **ลากแถบหัว** เพื่อย้ายตำแหน่งหน้าต่าง
- **ดับเบิลคลิก** งานเพื่อแก้ไข / **คลิกขวา** เพื่อเปลี่ยนสถานะหรือลบ
- **คลิกไอคอน ○ ◐ ✔** เพื่อสลับสถานะ
- **กดค้างแล้วลากงาน** ขึ้น-ลงเพื่อเรียงลำดับใหม่
- **◀ ▶** เลื่อนเดือน / **คลิกชื่อเดือน** กลับมาเดือนปัจจุบัน

## 📆 เชื่อม Google Calendar (เลือก 1 จาก 3 วิธี)

ตั้งค่าได้ที่ ⚙ → "แหล่งปฏิทิน" ทุกวิธีเป็นแบบ **อ่านอย่างเดียว**

### วิธีที่ 1: ลิงก์ Secret iCal (ง่ายสุด — บัญชี Gmail ส่วนตัว)
Google Calendar (เว็บ) → Settings → เลือกปฏิทิน → **Integrate calendar** →
คัดลอก **"Secret address in iCal format"** มาวางในตั้งค่า
> ⚠️ ลิงก์นี้เป็นความลับ ใครได้ไปจะเห็นปฏิทินทั้งหมด — ในแอพช่องนี้ถูก mask ไว้แบบ password
> ⚠️ บัญชีองค์กร (Google Workspace) แอดมินอาจปิดลิงก์นี้ไว้ → ใช้วิธีที่ 2 หรือ 3

### วิธีที่ 2: ไฟล์ .ics ในเครื่อง (ใช้ได้เสมอ แต่ไม่ auto)
Google Calendar → Settings → **Import & export** → Export → แตก zip →
ชี้ path ไปที่ไฟล์ .ics ในตั้งค่า (ต้อง export ใหม่เองเมื่อนัดเปลี่ยน)

### วิธีที่ 3: Google Calendar API + OAuth (สำหรับบัญชีองค์กรที่ปิดลิงก์แชร์)
1. [console.cloud.google.com](https://console.cloud.google.com) → สร้าง project
2. Enable **Google Calendar API**
3. OAuth consent screen → User type = **Internal** (สำหรับบัญชี Workspace)
4. Credentials → Create → OAuth client ID → **Desktop app**
5. นำ Client ID / Client Secret มาวางในตั้งค่า → กด **"เชื่อมต่อบัญชี Google"** → login ผ่านเบราว์เซอร์
6. เลือกแหล่งปฏิทินเป็น Google API → บันทึก

ข้อมูลปฏิทินรีเฟรชอัตโนมัติทุก 30 นาที และมี cache สำหรับตอน offline

## 📁 ไฟล์ที่โปรแกรมสร้าง (ห้าม commit ขึ้น git!)

| ไฟล์ | เก็บอะไร |
|---|---|
| `todo_data.json` | งานทั้งหมด + การตั้งค่า **รวมลิงก์ secret และ client secret** |
| `todo_data.backup.json`, `todo_data.backup2.json` | backup อัตโนมัติของไฟล์ข้างบน (มี secret เหมือนกัน) |
| `ical_cache.json` | cache รายการ event |
| `google_token.json` | OAuth token ของบัญชี Google |
| `worklog.json` | ประวัติงานที่ทำเสร็จ (ข้อมูลงานภายใน) |

ทุกไฟล์ข้างบนอยู่ใน `.gitignore` แล้ว อย่าเอาออก

## ⚠️ ข้อจำกัดที่ทราบ

- การอ่านไฟล์ .ics: event วนซ้ำรองรับแบบพื้นฐาน (รายวัน/สัปดาห์/เดือน/ปี + INTERVAL, COUNT, UNTIL)
  กฎซับซ้อนอย่าง `BYDAY=MO,WE,FR` จะยึดวันตามวันเริ่มต้นเท่านั้น
  → ถ้าใช้วิธี Google API ปัญหานี้หายไป เพราะ Google ขยาย event ให้เอง
- ใช้เฉพาะ "วันที่" ของ event ไม่สนใจเวลาและ timezone
- ลิงก์ iCal ของ Google ฝั่ง Google เองอาจ delay การอัพเดทหลายชั่วโมง
